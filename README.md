# Reconciliation examples

Worked bookkeeping reconciliation examples with real arithmetic: each folder holds
a small data file that adds up exactly and a README explaining the check. All
figures are fictional.

| Folder | What it shows | Guide |
|---|---|---|
| `proof-of-cash/` | A four-column proof of cash template and a script that checks it | [Proof of cash](https://www.zerabooks.com/proof-of-cash) |
| `scanned-statement-misreads/` | How one misread amount on a scanned statement shows up as a gap against the printed closing balance | [Scanned bank statement to Excel](https://www.zerabooks.com/scanned-bank-statement-to-excel) |
| `divorce-disclosure-timeline/` | One month of statements laid out for a financial disclosure, tied to opening and closing balances | [Bank statements for divorce](https://www.zerabooks.com/bank-statements-for-divorce) |
| `cleanup-statement-grid/` | A grid of accounts by month showing which statements are in, tied or off, worked oldest month first | [Bookkeeping cleanup](https://www.zerabooks.com/bookkeeping-cleanup) |
| `provider-switch-tie-out/` | Old books' balances at a cutover date tied to the new opening balances, with one uncleared check explained | [Bench alternative](https://www.zerabooks.com/alternatives/bench) |
| `bookkeeping-workload-estimate/` | Monthly bookkeeping hours estimated from statement line counts plus fixed jobs | [How much does a bookkeeper cost](https://www.zerabooks.com/how-much-does-a-bookkeeper-cost) |

Maintained by [ZeraBooks](https://www.zerabooks.com).
